# Installation Guide

Complete guide to installing Cool Terminal JSON configs.

## Prerequisites

- Windows 10/11 (Build 19041+)
- [Windows Terminal](https://microsoft.com/en-us/p/windows-terminal)
- Administrator access (optional)

## Installation Methods

### Method 1: Copy & Paste (Easiest)

**Step 1: Open Settings**
- Open Windows Terminal
- Press `Ctrl + ,`
- Click "Open JSON file" at bottom

**Step 2: Copy Config**
- Navigate to `configs/` folder
- Choose your favorite theme
- Open the `.json` file
- Copy all content (Ctrl + A, Ctrl + C)

**Step 3: Paste**
- Go back to settings.json window
- Select all (Ctrl + A)
- Paste (Ctrl + V)
- Save (Ctrl + S)

**Step 4: Restart**
- Close and reopen Windows Terminal

✅ **Done!**
